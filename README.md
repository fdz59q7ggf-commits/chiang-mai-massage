## 按摩小常識

- **泰式按摩（Thai）**：不用油、穿寬鬆衣服，拉筋按壓，力道偏重；不喜歡痛可說 "soft, please"。
- **腳底按摩（Foot）**：逛街走累最適合，約200～300銖/小時。
- **精油按摩（Oil）**：放鬆舒壓，價格約泰式的1.5倍。
